# project-exuviae

> “A hub for passive nodes: capture, describe, log.”

## What (v0.1)
- Passive Camera Node uploads snapshots to a central Hub.
- Hub generates scene descriptions and appends JSONL logs.
- Hub is the only coordinator (star topology).

## Status
- Spec-first (docs-driven) development.
- Implementation starts after v0.1 spec DoD is met.
